# 观察恢复与结果验证

## 点击后观察与错误处理

输入回执默认附带同一会话的新树 observation；它是输入后真实读取的完整页面，不代表页面已经加载完成。使用其中 observation_id 决定下一步，不例行再次 tree 消耗该凭据。观察失效时也会附带新树，但 executed=false 表示输入没有执行；必须重新判断目标，不重放旧坐标。observation_read_failed/observation_read_unavailable 时仅重试观察，动作回执仍保持原状态。

observation_required 是可恢复的观察失效，本次输入未执行，不是任务终点。优先读取回执的 observation 完整页面及 observation_id，重新决定下一步；未附有效观察才调用 tree/screenshot。executed=true 只代表输入已提交，依据新页面验证结果。读取失败只能重试观察，不重放整个输入。不要向用户只回复“需要重新观察”就结束任务。

- observation_required：本次输入未执行；重新观察，再决定目标与坐标，不重放旧动作。
- screen_route_required：旧前台租约不属于本次请求，create 同目标应用，由宿主重新决定位置；不能继续用旧凭据输入。
- observation_pending：只重读观察，不重放动作。
- outcome_unknown：先检查实际页面和原动作记录，不换 request_id 盲目重试。
- user_takeover / 用户暂停：等待用户新请求，不自行 close/create/resume 绕过。
- 权限交接、授权撤销：暂停并处理真实需求；主屏锁屏暂停，后台虚拟屏不因物理锁屏停止；不绕过用户暂停或身份验证。
- 空树或截图失败：不推断点击失败；允许一次短暂等待后重读，树仍空时改用同屏截图，截图也失败才报告真实观察状态，不编造主屏占用，不无限轮询。

输入法窗口是目标应用的输入辅助，不为键盘单独创建前台会话；只有操作输入法自己的设置才选择输入法包。failed/permission_required/not_supported 不占主屏租约；旧 session_id 不复用。用户可见的结果要通过新树或截图核验。

观察节奏：仅任务开始、动作后或需要验证当前状态时按需读取；同一会话 tree/screenshot 最短间隔 500ms，不按应用刷新事件推送截图。动态内容只标记页面变化；前台点击前复核观察中可点击目标的身份、文字和边界，目标相同可继续，目标变化、滚动导致目标移位、切页或用户接管则要求新观察。空页面/加载中时短暂等待再观察，不忙轮询。

## 连续推进与恢复

以用户目标为停止条件，打开应用、进入搜索框或输入搜索词后继续推进到所需结果。已授权的普通遮挡弹窗可在观察后关闭；找不到节点时可用真实截图定位。不因一次 observation_required 或短暂加载结束任务。

用户接管后必须等待用户的新请求。新请求明确要求继续，且系统状态允许时，恢复原会话并重新观察；新请求本身已经满足继续授权，不再要求重复发送“继续”。不要新建会话绕过尚未交回的控制权。权限、锁屏或必要信息真正缺失时，报告具体阻塞。

## 阶段与证据

复杂任务保持一份简短的当前阶段和未满足条件。每次开始、归零、重建路线或切换商品都会进入新阶段；旧阶段数据可以保留作历史，但最终回答只能组合当前阶段内经观察核对的结果。页面数字自然变化不等于子目标完成。

动作后关联本次 observation_id、页面状态和阶段。完成条件第一次全部满足时做一次最终逐项核对，然后停止无必要操作。连续两次输入后目标状态没有变化时，重新观察并更换策略；不要继续点近似坐标，也不要删除已经正确的状态来重来。最终回复逐项对应真实页面证据，例如归零后的秒表状态不能与归零前分段声称为同时存在。


观察恢复与完成判定：宿主对启动/短暂空树进行有界只读重试，tree 可能返回同屏图片；image_included 表示图片已附上，按该观察的坐标空间操作。input_outcome=submitted_once 仅说明动作提交一次，附带观察失败不改变该事实；禁止因此重放。page_ready_verified=false/effect_verified=false 表示业务效果仍需核对。切页后树/图冲突或页面加载中，重新观察确认目标，不能拿旧图坐标操作新树。连续两次没有目标状态变化时，停止近似坐标重复点击，重新定位或换树/图观察，仍无进展明确报告具体未完成步骤。购买场景“免密支付/提交订单/付款”都是最终提交边界，没有明确授权不得点击；不能把它们当普通规格下一步。

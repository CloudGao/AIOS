# Security

This preview has no dedicated public security contact or supported-release policy yet. A private reporting channel must be configured before public release. Do not post active credentials, personal conversations, notifications or device backups in public issues.

For local review, provide the affected version, minimal reproduction, permission boundary and a redacted sample. Keep disclosure details private until a channel is established.

Signing identities and API credentials belong outside version control. The source exporter excludes local state and dependency payloads, but automated pattern scanning is only a preliminary check. Review the exact files and artifacts being published.

Source builds and routine tests do not authorize device access or data erasure. Preserve recoverable backups before any device-wiping workflow.

# 使用与权限 / Usage

当前为源码准备预览，没有本次整理对应的正式下载地址或已验收公开安装包。

## APK

目标 Android 15+ / ARM64；主开发记录包含 vivo X200 Ultra / Android 16 和 Pixel / Android 17 的限定验证；当前候选需单独验收。
自行构建后安装自己的签名包，按应用内引导开启无线调试并完成本机配对/激活，再按需要授予悬浮窗、无障碍、通知读取和麦克风权限。只授予实际功能所需权限。已配对后，在总授权和无线调试开启时默认尝试自动恢复，可在激活页关闭；恢复不会自动重做中断的操作。无线调试关闭或配对失效时仍需用户处理。

在提供商设置配置自己有权使用的账号/API。主助手、云端工具及本地模型能力分别受配置和模型支持范围约束。不要将账号密钥写入源码。
通过首页助手按钮、系统助理入口或快捷设置磁贴打开助手；厂商电源键策略不保证遵循系统助理设置。
工作区管理会话、记忆、任务、技能和自动化；小程序页面管理发布内容及桌面入口。

## ROM

目标仅为 Pixel 10 frankel 的匹配 Lineage 基线。源码能够编译不代表发行包可安全安装。本预览不提供刷机命令，不将历史验收或已有设备状态当作全新安装通过。
实际设备安装需单独核对固件、签名、AVB、备份恢复与机型兼容性；涉及清空时先验证完整备份，再取得针对该次清空的明确确认。

## 数据与限制

本地 Workspace 和会话不意味着所有推理都离线。云端模型会接收所执行能力需要的输入；通知云端处理可能包含通知正文。由用户决定是否配置这些能力。
权限被撤销、屏幕安全限制、shell 能力缺失、OEM 后台限制和网络故障会影响执行。APK 同 UID 多进程不构成小程序权限隔离。
出现故障时提供去除凭据和私人内容的复现步骤，不上传原始会话、通知、设备备份或完整日志。

## 首次准备与语音

集中权限页显示基本就绪状态和按需能力，进入过页面不等于授权完成。麦克风检测由用户主动点击，短时采样不保存或上传；账号配置检查不替代真实网络与凭据验证。APK默认使用随包SenseVoice离线语音，支持中文/粤语、英语、日语、韩语，其余语言提示不支持。语音输入与云端助手推理是不同阶段。

## 按安装路线选择第三方组件

APK 在应用设置中选择助手语音识别模型／服务，账号和助手模型沿用已有配置。APK 不提供浏览器、邮箱或其他 ROM 应用选择目录。ROM 在系统管理中提供可选应用来源，并按实际装配模块显示本地文本、照片及声纹模型设置；可选应用默认不预装。

# AIOS 产品设计

当前源码基线由 ROM 与单 APK 两种宿主组成，核心业务共用。本文件描述产品现状；验证范围见 [VALIDATION](VALIDATION.md)。可选依赖改造已写入候选源码，已完成限定范围的 APK 设备验收；最终路线调整已验收，产物状态见 BUILD_ACCEPTANCE.md。

## 产品形态

ROM 目标为 LineageOS 24.0 / Pixel 10 frankel / ARM64。APK 目标为 Android 15+ / ARM64；主开发记录包含 vivo X200 Ultra / Android 16 与 Pixel / Android 17 的限定验证，公开候选需独立验收。APK 使用应用内无线 ADB 配对与 shell 服务，不依赖 Shizuku 或第二个辅助应用。已配对且总授权、无线调试开启时按退避策略恢复控制服务；用户可关闭自动恢复，旧操作不会自动续跑。

两种宿主共享助手会话、上下文、记忆/任务、技能、调度、通知事件和小程序业务。APK 不装入 ROM 通知治理、录音及会议纪要。公共功能不能因为 ROM 已验证就视为 APK 已验证。

## 用户功能

- 助手：文字、附件、语音输入，流式回复与历史、Markdown、审批与用户接管；运行中文字可排队或引导。
- Workspace：记忆、任务、会话投影和检索；数据保存在本机，云端推理按用户配置发送相应输入。
- 技能：随包指导与用户学习资产，按需读取正文；版本与证据由 Core 管理。
- 自动化：定时程序、事件触发助手与执行记录；运行受授权、资源池、网络和系统后台策略约束。
- MiniApps：本地小程序的发布、管理、打开与桌面入口。APK 使用系统快捷方式确认；同 UID 多进程不是权限隔离。
- 屏幕操作：主屏与虚拟屏观察/输入，按会话归属与授权执行；用户接管、锁屏、安全窗口、厂商权限有不同约束。
- ROM 扩展：通知规则/过滤/重要性/摘要、统一检索、录音与纪要以及 Lineage 系统集成。

## 界面与语言

原生 UI 默认按系统语言选择英文、简体或繁体资源，其他语言回退英文。助手普通轮次携带当前沟通语言；明确的用户语言要求优先。不能把英文回退当作完整翻译支持。运行时语言切换、RTL、语音支持范围按具体模块验收。

APK 首页包含概览、工作区和小程序页面，提供独立助手入口、系统助理入口和快捷设置磁贴。APK 默认离线引擎已改为 Whisper Small Q5_1；语言入口保留中文/粤语、英语、日语、韩语，粤语映射中文识别。当前已验证中英文样本，其他语言的同等质量未作保证；其他语言入口仍提示不支持。识别期间显示本地化前台通知并持有有时限的唤醒锁，完成或取消后释放；已通过锁屏连续中英文样本测试。初始化页检查模型、授权及账号配置，麦克风采样由用户主动触发；配置存在不等于网络或凭据验证成功。

## 当前限制

本地小模型通知分类存在质量限制，不能宣传全量准确率。云端分类需要显式配置且涉及通知内容处理。长期调度可靠性、多机型兼容性、APK 四屏并发与真实手指接管尚未全面验证；电源键唤起受厂商策略限制。
最近会话即时登记已有主开发限定设备记录，本次候选仅完成语音选择与相关设置界面的设备验收。小程序 ROM 分支、后台发布、多语言/RTL仍有验收缺口。

## 发布形态

一个源码仓库维护共享代码和两种宿主，安装包分别发行。模型和预编译依赖使用大小与 SHA-256 锁定，源码导出不携带内部 Git 历史或设备资料。自有代码采用 GPL-3.0-only；第三方原许可保持不变，见 LICENSING.md。多数依赖可从固定上游获取；模型用途限制、第三方再分发条件和全新环境构建仍是发布门槛，见 REDISTRIBUTION_REVIEW.md。

## 可选依赖（候选源码）

ROM 默认不再预装 Chromium、Collabora、MJ PDF、Text Editor、Kokoro，也不内置 LFM、CAM++ 和 BlazeFace 权重。模型管理提供固定兼容版本的官方来源；LFM/CAM++ 支持主动下载或导入，BlazeFace 支持转换版文件导入，大小和 SHA-256 校验后再落盘。尚未闭环的权重许可在界面明确标识，下载入口不代表许可放行。未安装声纹模型仍可转写；未安装或未验证人脸模型仍可做图片语义索引，人脸结果单独标记不可用，不能解释为零人脸。

仅 ROM 提供可选应用的官方来源、Android 已安装应用、默认应用和 TTS 设置入口。APK 不提供第三方应用目录，只显示实际装配的模型/服务选择（当前为助手语音识别服务和账号模型配置）。系统负责实际安装与应用选择；浏览器自动化仍依赖兼容 Chromium 的 CDP 通道。APK 不提供未装配的 ROM 模型功能。照片语义模型已使用 OpenCLIP，助手及会议转写共用 Whisper 后端；模型选择仍按 APK/ROM 实际装配范围展示。详情见 OPTIONAL_DEPENDENCIES.md；限定范围的设置交互、应用语言切换及 RTL 已验收，完整边界见 VALIDATION.md。

最新选择入口：OpenCLIP 支持当前配对模型或停用，保留既有文件/索引；Whisper 与系统/已安装 Android 识别服务可供后续助手语音输入选择。会议批量转写也使用 Whisper。BlazeFace 仅支持稠密转换版导入，官方稀疏文件不能直接加载。
